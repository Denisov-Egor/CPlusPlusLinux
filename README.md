## 📖 О проекте

**CPlusPlusLinux** — учебный репозиторий для систематического изучения **C++** в среде **Linux**.

Здесь собраны практические упражнения, задачи, алгоритмы и небольшие проекты, которые помогают закреплять изученные возможности языка на практике.

Основная цель — постепенно перейти от базового синтаксиса C++ к более сложному программированию и системной разработке под Linux.

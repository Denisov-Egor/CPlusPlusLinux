## О проекте

**CPlusPlusLinux** — мой учебный репозиторий для последовательного изучения C++ и практики разработки в Linux.

Здесь собраны упражнения по отдельным темам языка, алгоритмические задачи и небольшие проекты. Я использую их, чтобы разбираться в принципах работы кода, закреплять материал самостоятельно и постепенно переходить к более сложным задачам.

Основной акцент — на понятном коде, осмысленной практике и понимании того, как работают используемые инструменты.

## Сборка и запуск

Для компиляции отдельного файла с помощью GCC используйте терминал из корня репозитория:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic path/to/source.cpp -o app
./app
```

Замените `path/to/source.cpp` на путь к нужному файлу. Если программа состоит из нескольких исходных файлов, их необходимо передать компилятору вместе.

- `-std=c++20` — использовать стандарт C++20;
- `-Wall -Wextra -Wpedantic` — включить дополнительные предупреждения компилятора.

Для отдельных учебных задач достаточно прямой компиляции. Системы сборки вроде CMake имеет смысл подключать там, где проект действительно этого требует.

## Направление развития

Мой текущий учебный маршрут — закрепить основы C++, научиться уверенно работать с данными и памятью, затем углубиться в стандартную библиотеку, проектирование программ и системные возможности Linux.

В дальнейшем планирую изучать:

- контейнеры и алгоритмы стандартной библиотеки;
- классы, инкапсуляцию и RAII;
- управление ресурсами и умные указатели;
- файловые операции;
- шаблоны и обработку ошибок;
- многопоточность и сетевое программирование;
- системное программирование в Linux.

Это направления дальнейшего обучения, а не утверждение, что все перечисленные темы уже освоены.

## Принцип обучения

Для каждой новой темы я стараюсь пройти путь от понимания основ до самостоятельного применения:

1. Разобраться в концепции.
2. Решить практические задачи.
3. Использовать тему вместе с ранее изученным материалом.
4. Закрепить знания на более цельной задаче или мини-проекте.
5. Проверить и улучшить собственный код.

Я стремлюсь не просто получить работающий результат, а понимать, почему он работает и какие решения делают код проще и надёжнее.

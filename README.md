## О проекте

**CPlusPlusLinux** — мой учебный репозиторий, посвящённый изучению C++ и практике разработки в Linux.

Здесь собраны упражнения по различным темам языка, алгоритмические задачи и небольшие учебные проекты. Репозиторий отражает процесс обучения: от базовых конструкций языка до более сложных механизмов и принципов организации программ.

Главная цель — не просто получать работающий код, а понимать используемые механизмы, самостоятельно находить решения и постепенно улучшать качество программ.

## Изучаемые темы

В репозитории представлены материалы и практика по следующим направлениям:

- **Основы языка:** переменные, типы данных, ввод и вывод.

- **Работа с данными:** одномерные и двумерные массивы, строки, `std::string`.
- **Управление памятью:** ссылки, указатели и динамическая память.

- **Моделирование данных:** структуры и перечисления.
- **Объектно-ориентированное программирование:** классы, инкапсуляция, конструкторы и деструкторы.
- **Алгоритмическая практика:** решение задач, в том числе с платформы CSES.

Содержание репозитория постепенно расширяется по мере изучения новых тем.

## Компиляция и запуск

Для сборки отдельных учебных задач используется GCC.

Перейдите в корневой каталог репозитория и выполните:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic path/to/source.cpp -o app
./app
```

Замените `path/to/source.cpp` на путь к нужному исходному файлу.

**Используемые параметры компилятора:**

| Параметр | Назначение |
|---|---|
| `-std=c++20` | Использование стандарта C++20 |
| `-Wall` | Включение основных предупреждений |
| `-Wextra` | Дополнительные предупреждения |
| `-Wpedantic` | Проверка соответствия стандарту |

Для программ из нескольких исходных файлов необходимо передать компилятору все необходимые `.cpp` файлы.

## Принципы обучения

В процессе изучения языка придерживаюсь нескольких принципов:

- **Понимание** — разбираться в том, как работают используемые механизмы.
- **Самостоятельность** — сначала искать решение самостоятельно.
- **Простота** — стремиться к понятному и читаемому коду.
- **Разделение ответственности** — организовывать программу так, чтобы каждая часть выполняла свою задачу.
- **Практика** — закреплять теорию решением задач и созданием проектов.
- **Улучшение** — анализировать написанный код и искать более удачные решения.

Мой подход к изучению новой темы:

1. Изучить концепцию и разобраться в принципах работы.
2. Решить практические задачи.
3. Применить новые знания вместе с ранее изученным материалом.
4. Закрепить тему на мини-проекте.
5. Проверить, проанализировать и улучшить собственный код.
